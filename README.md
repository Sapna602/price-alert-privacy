# Privacy Policy for Price Alert Monitor

**Price Alert Monitor** is a browser extension designed to monitor stock and crypto trading prices on active web pages and provide visual and audio notifications when user-defined percentage thresholds are met.

### Data Collection and Usage
- **No Personal Data Collection:** We do not collect, store, transmit, or share any personal identifiable information (PII), financial information, or browsing history.
- **Local Storage:** All user preferences (such as custom percentage threshold settings) are stored locally on your device using the browser's `chrome.storage.local` API. This data never leaves your device and is not sent to any external servers.
- **Permissions:** The extension uses `activeTab` permission solely to read price data from the active trading page to execute alerts and enable CSV log exports locally.

### Contact Information
If you have any questions or concerns about this privacy policy, you can reach out via GitHub.
